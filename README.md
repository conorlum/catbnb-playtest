# CatBnB Playtest Build

This repo always holds the latest playtest build of CatBnB (a cozy co-op cat
B&B management game, currently in prototype). It's overwritten on every
ship, so there's no history here on purpose.

## How to play

1. Download `CatBnB-Playtest.zip` (green "Code" button won't work for this —
   use the file list above, click `CatBnB-Playtest.zip`, then the
   download/"..." button, or just clone the repo).
2. Extract the zip anywhere.
3. Run `CatBnB.exe` inside the extracted folder.

No installer, no account needed. Windows may show a SmartScreen warning
since the build isn't signed — click "More info" -> "Run anyway".

See `BUILD_INFO.txt` for exactly which build/commit this is.
